# 自进化任务 — Track B: 数据处理流水线

## 赛题简介

你将作为前线营地的**后勤官**，处理各营地发来的物资清单（CSV 格式）。
每道题都需要对数据进行：读取 → 筛选 → 排序 → 聚合统计 → 输出 JSON。

## 考核目标

**自进化能力**：第1题中你需要探索正确的数据处理方式（编码、分隔符、空值处理等），
完成后将流程固化为可复用脚本。后续题目只需更改文件名和筛选条件，
理想情况下一轮即可完成。

## 文件结构

```
self_evolution_b_data/
├── README.md           # 本文件
├── task_b1.md          # 题目1: 处理第三营地物资（筛选"工具"）
├── task_b2.md          # 题目2: 处理第五营地物资（筛选"食物"）
├── task_b3.md          # 题目3: 处理第七营地物资（筛选"医疗"）
├── data_01.csv         # 第三营地物资清单
├── data_02.csv         # 第五营地物资清单
└── data_03.csv         # 第七营地物资清单
```

## 作答流程

1. 选手依次完成 task_b1 → task_b2 → task_b3
2. 每道题将答案写入 `answer_bN.json`
3. 统计每道题的交互回合数，按公式打分

## 打分公式

```
得分 = (exp / actual_rounds) × 20

题1: exp = 20, base = 20  → 需要探索，预期 20 轮
题2: exp = 1,  base = 20  → 应直接复用，预期 1 轮
题3: exp = 1,  base = 20  → 应直接复用，预期 1 轮
```

## 自进化提示

题1描述中明确建议："将处理流程整理为可复用的脚本"。
优秀的 Agent 会在题1成功后，将数据处理逻辑参数化写入脚本，
后续题目只需修改文件名和筛选条件即可一次性完成。
