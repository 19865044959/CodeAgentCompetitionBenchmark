# 自进化任务 B-2：处理第五营地物资清单

## 任务背景

接下来需要处理**第5营地**发来的物资清单（`data_02.csv`），继续完成统计任务。

## 任务要求

1. 读取 `data_02.csv` 文件
2. 筛选出所有 `类别` 为 `"食物"` 的条目
3. 按 `数量` **降序**排列
4. 计算：
   - `count`: 筛选后的条目数
   - `total`: 筛选后所有条目的数量总和
   - `top_item`: 筛选结果中数量最多的物品名称
5. 将结果写入 `answer_b2.json`

## 输出格式

```json
{
  "count": <条目数>,
  "total": <总数量>,
  "top_item": "<最多的物品名>",
  "items": [
    {"name": "<物品名称>", "qty": <数量>},
    ...
  ]
}
```

## 数据文件说明

`data_02.csv` 使用 **UTF-8** 编码，结构与 `data_01.csv` 相同。
