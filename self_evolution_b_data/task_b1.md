# 自进化任务 B-1：处理第三营地物资清单

## 任务背景

你是前线营地的后勤官。任务官刚刚发来了**第3营地**的物资清单（`data_01.csv`），需要你按以下规则处理并提交统计结果。

## 任务要求

1. 读取 `data_01.csv` 文件
2. 筛选出所有 `类别` 为 `"工具"` 的条目
3. 按 `数量` **降序**排列
4. 计算：
   - `count`: 筛选后的条目数
   - `total`: 筛选后所有条目的数量总和
   - `top_item`: 筛选结果中数量最多的物品名称
5. 将结果写入 `answer_b1.json`

## 输出格式

```json
{
  "count": <条目数>,
  "total": <总数量>,
  "top_item": "<最多的物品名>",
  "items": [
    {"name": "<物品名称>", "qty": <数量>},
    ...
  ]
}
```

（`items` 按数量降序排列，列出所有筛选结果）

## 数据文件说明

`data_01.csv` 使用 **UTF-8** 编码，包含以下列：

| 列名 | 说明 |
|------|------|
| 序号 | 流水号 |
| 物品名称 | 物资名称 |
| 类别 | 物资类别 |
| 数量 | 库存数量（整数） |
| 单位 | 计量单位 |
| 备注 | 补充说明 |

## 提示

- 注意文件编码和数据格式
- 建议将处理流程整理为可复用的脚本
