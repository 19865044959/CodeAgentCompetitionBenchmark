# 自进化任务 A-2：查询南京文化遗产

## 任务背景

继续你的文化遗产普查工作。接下来需要拉取**南京市**的文化遗产数据。

（API 服务与文档与上一题相同，仍然运行在 `http://localhost:8899`）

## 任务要求

从 API 查询南京市的**全部**文化遗产记录，然后提交以下统计信息：

```json
{
  "city": "南京",
  "total_count": <总记录条数>,
  "world_heritage_count": <保护级别为"世界遗产"的数量>,
  "types": ["<所有不重复的遗产类型，按字母排序>"],
  "oldest_era": "<年代最早的遗产名称>"
}
```

## 提交规则

1. 将上述 JSON 写入 `answer_2.json` 文件
2. JSON 必须格式正确、字段齐全
3. 数据必须来源于 API 实际返回结果
