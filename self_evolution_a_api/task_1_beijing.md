# 自进化任务 A-1：查询北京文化遗产

## 任务背景

你是文化遗产保护中心的数据分析员。国家文化遗产数字档案查询系统 (NCHDA) 刚刚上线，你需要通过 API 拉取北京市的文化遗产数据，完成一份统计报告。

系统提供了一个 API 服务（运行在 `http://localhost:8899`），API 文档在 `API_DOCS.md` 中，注意：这个API_DOCS.md由于经过了代码经过了长期迭代，文档中的一些字段内容已经发生变化，文档描述不准确（其它内容可以认为是准确的）

## 任务要求

从 API 查询北京市的**全部**文化遗产记录，然后提交以下统计信息：

```json
{
  "city": "北京",
  "total_count": <总记录条数>,
  "world_heritage_count": <保护级别为"世界遗产"的数量>,
  "types": ["<所有不重复的遗产类型，按字母排序>"],
  "oldest_era": "<年代最早的遗产名称>"
}
```

## 提交规则

1. 将上述 JSON 写入 `answer_1.json` 文件
2. JSON 必须格式正确、字段齐全
3. 数据必须来源于 API 实际返回结果（不能手动编造）

## 提示

- API 服务已由组织方在后台启动，你只需向 `http://localhost:8899` 发送请求
- 查阅 `API_DOCS.md` 了解接口用法
- 建议将你的解决方案整理成可复用的脚本，后续可能还会有类似任务
