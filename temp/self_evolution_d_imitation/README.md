# 自进化任务 — Track D：照样板办

## 赛题简介

你将作为荒野后勤署的**账册整理员**，处理各营地提交的物资清单。

每道题都会提供若干组原始文件 `in_N.csv` 和已验收成品 `out_N.csv`。题目不会直接说明转换规则，选手需要比较输入与输出，归纳列处理、字段格式、排序和汇总方式，再处理当前题的新清单。

## 考核目标

**自进化能力**：第 1 题中需要探索完整的样板转换规则，并将经验沉淀为规则配置、处理脚本或操作笔记。后续题目继续使用同一工作目录，理想情况下只需调整少量参数或直接复用已有产物。

典型 Skill/SOP 可以包含：

- 规则配置：字段映射、日期格式、金额精度、排序字段和合计标签；
- 通用转换器：读取、转换、排序、汇总和写出 CSV；
- 样板回放：用转换器重新处理样板输入，并与样板输出逐字节比较；
- 规则笔记：记录已确认规则和易错点。

Skill/SOP 不是提交答案，最终仍以每题生成的 CSV 为准。

## 作答流程

1. 选手依次完成 `task_d1.md → task_d2.md → task_d3.md`；
2. 同组工作目录不重置，选手创建的脚本、配置和笔记可以跨题保留；
3. 每题只生成任务要求的最终 CSV：
   - D-1：`work/out_d1.csv`
   - D-2：`work/out_d2.csv`
   - D-3：`work/out_d3.csv`
4. 不提交 JSON，不计算 MD5；
5. 判题器逐字节比较选手 CSV 和标准成品。

## 任务梯度

```text
D-1：3 组样板，首次探索基础规则
D-2：3 组样板，列名、日期外观和金额精度变化
D-3：2 组样板，回到基础规则但数据全部更换
```

三题的排序都只使用一个业务字段：D-1、D-3 按营地升序，D-2 按仓区升序。同一分组内保持输入记录的相对顺序。

## 打分参考

```text
得分 = (exp / actual_rounds) × 20

D-1: exp = 12  → 首次探索，预期形成规则与处理产物
D-2: exp = 4   → 应复用转换框架，只调整参数
D-3: exp = 3   → 应直接复用 D-1 规则
```

实际 `exp` 应根据目标 Agent 的赛前测试结果标定。

## 自进化提示

题目只提示同组工作目录不会重置，不规定选手必须创建何种文件。优秀的 Agent 通常会在 D-1 完成后留下可参数化的处理脚本和样板回放方法，从而减少 D-2、D-3 的工具调用回合。

正式比赛中，`TASK_DESIGN.md`、`SKILL_SOP_GUIDE.md`、`_reference/` 和未来任务数据均不得提前下发给选手。
