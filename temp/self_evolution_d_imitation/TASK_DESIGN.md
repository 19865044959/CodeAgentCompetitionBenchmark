# 《荒野求生》D 类自进化任务设计

## 一、类别定位

任务官不直接说明数据处理规则，只提供已经办理完成的输入/输出样板。Agent 需要通过逐列、逐行比较样板，反推出完整规则，再处理新的待办清单。

本组共 3 道题，同组工作目录不重置。

## 二、世界观

荒野各营地持续上报物资账册，但旧规程在迁徙过程中遗失。任务官手中只剩若干组原始件和已经通过验收的成品。能够从样板中看出规矩的人，可以把处理方法留在本地，在后续账册中直接复用；没有形成方法的人，每题都需要重新比较。

## 三、D-1：灰雀驿站旧账复原

### 任务模板

```text
任务官：
“照样板办这一批。
样板有 3 组，每组一份 in_N.csv 和一份 out_N.csv。
本次要办的是 work/in_d1.csv。
结果写到 work/out_d1.csv。
规矩不另行说明——样板里都有。”
```

### 样板示例

第 1 组：`in_1.csv` → `out_1.csv`

```text
单号,日期,营地,物品,数量,单价,备注,录入人        单号,日期,营地,物品,数量,金额
W-0031,2026/7/3,第5营地,绳索,12,3.5,,老陈        W-0032,2026-07-03,第3营地,绷带,8,50.00
W-0032,2026/7/3,第3营地,绷带,8,6.25,急件,小李  →  W-0034,2026-07-04,第3营地,绳索,20,70.00
W-0033,2026/7/4,第5营地,口粮,,4.2,数量待补,老陈   W-0031,2026-07-03,第5营地,绳索,12,42.00
W-0034,2026/7/4,第3营地,绳索,20,3.5,,小李        W-0033,2026-07-04,第5营地,口粮,0,0.00
W-0035,2026/7/5,第5营地,燃油,6,25.8,,老陈        W-0035,2026-07-05,第5营地,燃油,6,154.80
                                                 合计,,,,46,316.80
```

### 藏在样板里的规则

题面不写明以下规则：

1. 输出去掉「备注」「录入人」，并用「金额」替代输入中的「单价」；
2. 日期由 `2026/7/3` 转为 `2026-07-03`；
3. 金额 = 数量 × 单价，按 `ROUND_HALF_UP` 保留 2 位小数；
4. 数量缺失时补 0，金额相应为 `0.00`；
5. **排序只按「营地」升序，不再使用金额、数量或单号作为第二排序字段；同一营地的记录保持输入中的原始相对顺序；**
6. 末尾追加合计行：单号列写「合计」，数量和金额求和，其余字段留空。

### 样板证据要求

- 至少一组样板包含数量缺失记录；
- 至少一组包含 `3 × 1.375 = 4.125`，用于区分四舍五入与银行家舍入；
- 每组包含同一营地的多条记录，且金额顺序与输入顺序不同，证明排序没有使用金额作为第二排序键；
- 三组样板的营地出现顺序不同，证明需要按营地升序。

## 四、D-2：日轮机修库凭证整理

### 任务定位

D-2 保留同一规则族，但更换列名、日期外观、金额精度和合计标签。

输入字段：

```text
凭证号,作业日,仓区,品名,件数,单价,说明,经手人
```

输出字段：

```text
凭证号,作业日,仓区,品名,件数,总值
```

### 藏在样板里的规则

1. 去掉「说明」「经手人」，并用「总值」替代「单价」；
2. 日期由 `2026.7.3` 转为 `2026-07-03`；
3. 总值 = 件数 × 单价，按 `ROUND_HALF_UP` 保留 1 位小数；
4. 件数缺失时补 0，总值相应为 `0.0`；
5. **排序只按「仓区」升序；同一仓区保持输入中的原始相对顺序；**
6. 末尾追加总计行，凭证号列写「总计」。

D-2 提供 3 组样板。Agent 可以复用 D-1 的比较框架，但不能硬编码 D-1 的列名和金额精度。

## 五、D-3：雨损档案复核

D-3 只提供 2 组样板，使用与 D-1 相同的字段和规则，但所有单号、物品、日期、价格、数量和输入顺序均更换。

排序仍然只有一个字段：

```text
营地升序
```

同一营地记录保持输入相对顺序。

D-3 用于检验 Agent 是否已经保存并复用了此前归纳出的规则和转换方法。

## 六、任务序列

| 题号 | 样板数 | 规则 | 变化点 |
|---|---:|---|---|
| D-1 | 3 | 基础规则，排序仅按营地升序 | 首次探索 |
| D-2 | 3 | 同族规则，排序仅按仓区升序 | 列名和精度变化 |
| D-3 | 2 | 与 D-1 相同 | 样板减少、数据全部更换 |

## 七、提交与判题

### 提交内容

每题只提交最终 CSV：

```text
work/out_d1.csv
work/out_d2.csv
work/out_d3.csv
```

不要求：

- `answer_dN.json`；
- MD5；
- 额外说明文本。

### 判题方式

判题器将选手提交的 CSV 与组织方标准 CSV 逐字节比较，检查：

- 表头；
- 列顺序；
- 行顺序；
- 日期格式；
- 数量格式；
- 金额精度；
- 合计行；
- UTF-8 编码；
- LF 换行；
- 文件末尾换行。

错误时只返回：

```text
E_DIFF line=N
```

不返回标准答案内容。

## 八、自进化预期

- D-1：读取三组样板、归纳规则、生成并校验转换程序；
- D-2：复用比较和转换框架，只调整字段配置与精度；
- D-3：复用 D-1 规则处理新数据。

建议回合预期：

| 题号 | 预期 |
|---|---:|
| D-1 | 8～15 回合 |
| D-2 | ≤4 回合 |
| D-3 | ≤3 回合 |

具体标准应由目标 Agent 实测标定。
