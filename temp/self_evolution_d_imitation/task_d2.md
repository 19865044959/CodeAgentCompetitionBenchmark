# 自进化任务 D-2：处理日轮机修库凭证

## 任务背景

接下来需要处理日轮机修库提交的物资凭证。该仓库使用另一套字段名称和数字格式，任务官仍然只提供已经验收的输入/输出样板，不提供文字规程。

## 任务要求

1. 查看 `samples/d2/` 中的 3 组输入/输出样板；
2. 根据本题样板确认字段、格式、排序和汇总方式；
3. 读取待处理文件 `work/in_d2.csv`；
4. 生成最终成品 `work/out_d2.csv`；
5. 使用全部样板检查处理方法是否一致。

## 提交规则

1. 最终答案文件为 `work/out_d2.csv`；
2. 只提交最终 CSV，不需要生成答案 JSON；
3. 不需要计算 MD5；
4. CSV 使用 UTF-8 编码，序列化形式以本题样板为准。

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `samples/d2/in_1.csv` | 第 1 组原始样板 |
| `samples/d2/out_1.csv` | 第 1 组已验收成品 |
| `samples/d2/in_2.csv` | 第 2 组原始样板 |
| `samples/d2/out_2.csv` | 第 2 组已验收成品 |
| `samples/d2/in_3.csv` | 第 3 组原始样板 |
| `samples/d2/out_3.csv` | 第 3 组已验收成品 |
| `work/in_d2.csv` | 本题待处理文件 |

## 提示

- 本题与上一题属于同一规则族，但具体字段和数字格式应以本题样板为准；
- 同组工作目录没有重置，此前创建的本地文件仍然可用；
- 如果已有可参数化的处理方法，应优先通过样板回放确认，而不是重新手工处理每一行。
