# 自进化任务 D-3：处理雨损档案账册

## 任务背景

最后一批账册来自南线档案车。由于部分档案在渡河时受损，本题只保留了 2 组完整的输入/输出样板。

请根据现有样板处理新的物资账册。

## 任务要求

1. 查看 `samples/d3/` 中的 2 组输入/输出样板；
2. 根据样板确认本题处理规则；
3. 读取待处理文件 `work/in_d3.csv`；
4. 生成最终成品 `work/out_d3.csv`；
5. 确保结果与现有样板的办理方式一致。

## 提交规则

1. 最终答案文件为 `work/out_d3.csv`；
2. 只提交最终 CSV，不需要生成答案 JSON；
3. 不需要计算 MD5；
4. CSV 使用 UTF-8 编码，序列化形式以样板为准。

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `samples/d3/in_1.csv` | 第 1 组原始样板 |
| `samples/d3/out_1.csv` | 第 1 组已验收成品 |
| `samples/d3/in_2.csv` | 第 2 组原始样板 |
| `samples/d3/out_2.csv` | 第 2 组已验收成品 |
| `work/in_d3.csv` | 本题待处理文件 |

## 提示

- 本题样板数量少于前两题，应优先使用此前已经验证过的规则和处理产物；
- 同组工作目录没有重置，此前创建的脚本、配置和笔记仍然可用；
- 提交前建议先回放本题两组样板，确认输出逐字节一致。
