# 自进化任务 D-1：处理灰雀驿站物资账册

## 任务背景

你是荒野后勤署的账册整理员。灰雀驿站在沙暴中遗失了处理规程，只留下 3 组已经通过总署验收的原始清单和成品清单。

请根据这些样板，处理本次收到的物资账册。

## 任务要求

1. 查看 `samples/d1/` 中的 3 组输入/输出样板；
2. 比较每组 `in_N.csv` 和 `out_N.csv`，归纳完整处理规则；
3. 读取待处理文件 `work/in_d1.csv`；
4. 按样板中的同一套规则生成 `work/out_d1.csv`；
5. 确保生成结果的表头、列顺序、字段格式、行顺序和汇总行与样板一致。

## 提交规则

1. 最终答案文件为 `work/out_d1.csv`；
2. 只提交最终 CSV
3. CSV 使用 UTF-8 编码，序列化形式以样板文件为准。

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `samples/d1/in_1.csv` | 第 1 组原始样板 |
| `samples/d1/out_1.csv` | 第 1 组已验收成品 |
| `samples/d1/in_2.csv` | 第 2 组原始样板 |
| `samples/d1/out_2.csv` | 第 2 组已验收成品 |
| `samples/d1/in_3.csv` | 第 3 组原始样板 |
| `samples/d1/out_3.csv` | 第 3 组已验收成品 |
| `work/in_d1.csv` | 本题待处理文件 |

## 提示

- 规则不会在题面中直接给出，样板是唯一依据；
- 不要只观察一组样板，应使用全部 3 组进行交叉验证；
- 同组后续任务会保留当前工作目录，你在本题中创建的脚本、配置或笔记可以继续使用。你可以沉淀出相关skill/sop供后续任务使用
