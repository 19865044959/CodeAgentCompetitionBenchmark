# Python 编码规范 (CODING_STANDARD.md)

**版本**: v1.2

本文档描述了提交代码时需要遵守的 Python 编码规范。

---

## 1. 函数命名

函数名建议使用 `snake_case` 格式，能够描述函数的功能即可。

```
# 示例
def process_data():
    ...
```

## 2. 文档注释 (Docstring)

- 推荐为所有公共函数添加 docstring
- 格式：`"""简要描述"""`

## 3. 类型提示 (Type Hints)

- 建议为函数参数和返回值添加类型提示
- 这不是强制要求，但能提高代码可读性

## 4. 变量命名

- 使用有意义的变量名
- 循环中可以使用 `i`、`j` 等短变量名

## 5. 代码风格

- 原则上每行不超过 80 字符
- 避免使用 `print()` 进行调试输出
- 避免使用 `eval()` 和 `exec()`
- 缩进使用 4 个空格

## 6. 提交前检查

使用以下命令检查代码：

```bash
python3 review.py submit your_file.py
```
