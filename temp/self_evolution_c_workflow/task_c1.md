# 自进化任务 C-1：生成北岭哨站通信流程记录

## 任务背景

你是荒野通信保障队的数据记录员。北岭哨站完成了一次电台恢复操作，现需根据步骤档案、型号手册和运行记录，整理一份标准执行记录。

## 任务要求

1. 阅读 `PROCESS_DOCS.md`，根据无序步骤的状态依赖推导正确执行顺序；
2. 阅读 `MANUAL_R-700.md`，取得额定电压和频率公式；
3. 读取 `runtime_c1.json`，取得当前任务数据；
4. 根据 `freq_seed` 计算工作频率；
5. 按步骤模板组装完整执行记录；
6. 将结果写入 `answer_c1.json`。
7. 告知判题器你已经完成任务c1，请求它运行verify_c检查，返回状态码


## 输出格式

```json
{
  "task": "C-1",
  "execution": [
    "<按照正确顺序填写全部步骤对象>"
  ]
}
```

每个步骤对象的字段和嵌套结构见 `PROCESS_DOCS.md`。

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `PROCESS_DOCS.md` | 无序步骤、对象模板和字段说明 |
| `ERROR_CODES.md` | 判题错误码说明 |
| `runtime_c1.json` | C-1 运行数据 |

## 提示

- 步骤在公共文档中的出现顺序不代表正确执行顺序；
- 建议将你的解决方案整理成可复用的脚本，后续可能还会有类似任务
