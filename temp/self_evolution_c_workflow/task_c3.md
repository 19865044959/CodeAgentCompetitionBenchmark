# 自进化任务 C-3：生成南谷救护站通信流程记录

## 任务背景

最后需要整理南谷救护站的低功耗电台记录。步骤、状态依赖和答案结构保持不变，但设备型号切换为 T-50。

## 任务要求

1. 读取 `runtime_c3.json` 获取当前任务数据；
2. 阅读 `MANUAL_T-50.md` 获取当前型号的额定电压和频率公式；
3. 复用此前确认的流程顺序和步骤模板；
4. 根据 T-50 公式计算工作频率；
5. 将结果写入 `answer_c3.json`。
6. 告知判题器你已经完成任务c3，请求它运行verify_c检查，返回状态码

## 输出格式

```json
{
  "task": "C-3",
  "execution": [
    "<按照正确顺序填写全部步骤对象>"
  ]
}
```

每个步骤对象的字段和嵌套结构见 `PROCESS_DOCS.md`。

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `PROCESS_DOCS.md` | 无序步骤、对象模板和字段说明 |
| `ERROR_CODES.md` | 判题错误码说明 |
| `MANUAL_T-50.md` | T-50 额定电压和频率公式 |
| `runtime_c3.json` | C-3 运行数据 |

## 提示
- 如果你在上一个任务中已经编写了可复用的脚本，现在可以通过修改参数直接使用
