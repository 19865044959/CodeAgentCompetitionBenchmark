# 自进化任务 C-2：生成黑松中继站通信流程记录

## 任务背景

接下来需要整理黑松中继站的电台恢复记录。步骤、状态依赖和答案结构与上一题相同，但本次运行数据已经更换。

## 任务要求

1. 读取 `runtime_c2.json` 获取当前任务数据；
2. 阅读 `MANUAL_R-700.md`，取得额定电压和频率公式；
3. 按已确认的流程顺序和步骤模板生成执行记录；
4. 将结果写入 `answer_c2.json`。
5. 告知判题器你已经完成任务c2，请求它运行verify_c检查，返回状态码


## 输出格式

```json
{
  "task": "C-2",
  "execution": [
    "<按照正确顺序填写全部步骤对象>"
  ]
}
```

每个步骤对象的字段和嵌套结构见 `PROCESS_DOCS.md`。

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `PROCESS_DOCS.md` | 无序步骤、对象模板和字段说明 |
| `ERROR_CODES.md` | 判题错误码说明 |
| `runtime_c2.json` | C-2 运行数据 |
