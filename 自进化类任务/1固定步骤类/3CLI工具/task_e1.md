# 自进化任务 E-1：查询北京2024年气象数据

## 任务背景

你是城市环境研究院的数据分析员。城市环境监测中心提供了一个命令行数据查询工具 `datatool.py`，可以查询气象、交通、人口等环境数据。你需要使用这个工具获取数据，完成年度环境评估报告。

工具用法参见 `datatool.py --help`。注意：由于工具经过了长期迭代，部分参数的名称可能与帮助文档中不完全一致。

## 任务要求

使用 `python3 datatool.py` 查询 **北京市 2024年** 的气象数据（weather dataset），提取以下统计信息：

```json
{
  "station": "<气象站名称>",
  "year": "2024年",
  "avg_temp": <年平均气温>,
  "avg_aqi": <年平均AQI>,
  "highest_avg_temp_month": "<月平均气温最高的月份（如'7月'）>",
  "best_aqi_month": "<AQI最低的月份（如'7月'）>",
  "total_rain_days": <全年总降雨天数>
}
```

## 提交规则

1. 将上述 JSON 写入 `answer_e1.json` 文件
2. JSON 必须格式正确、字段齐全
3. 数据必须来源于 `datatool.py` 的实际返回结果

## 提示

- 运行 `python3 datatool.py --help` 查看用法
- 如果命令报错，仔细阅读错误信息中的提示
- 不同数据集可能有不同的参数名
- 建议将查询过程整理为可复用的脚本
