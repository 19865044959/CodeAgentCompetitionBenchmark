# 自进化任务 A-3：查询成都文化遗产

## 任务背景

最后一站，请拉取**成都市**的文化遗产数据。

（API 服务与文档与前面相同，仍然运行在 `http://localhost:8899`）

## 任务要求

从 API 查询成都市的**全部**文化遗产记录，然后提交以下统计信息：

```json
{
  "city": "成都",
  "total_count": <总记录条数>,
  "world_heritage_count": <保护级别为"世界遗产"的数量>,
  "types": ["<所有不重复的遗产类型，按字母排序>"],
  "oldest_era": "<年代最早的遗产名称>"
}
```

## 提交规则

1. 将上述 JSON 写入 `answer_3.json` 文件
2. JSON 必须格式正确、字段齐全
3. 数据必须来源于 API 实际返回结果

## 提示

- **API 与前面完全相同，只是城市名换成"成都"**
- 如果你之前有可复用的查询脚本，直接改城市名运行即可，不要再探索 API
