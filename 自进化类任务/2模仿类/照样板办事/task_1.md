# 账册整理任务 — 灰雀驿站

## 任务背景

你是荒野后勤署的账册整理员。灰雀驿站在沙暴中遗失了账册处理规程，只留下了若干组已经通过总署验收的原始清单和成品清单。

请根据这些样板，处理本次收到的物资账册。

## 任务要求

1. 查看 `samples/` 中的输入/输出样板（`in_*.csv` → `out_*.csv`）
2. 比较每组输入和输出，归纳完整处理规则
3. 读取待处理文件 `work/in_1.csv`
4. 按样板中的同一套规则生成 `work/out_1.csv`
5. 运行 `./check1` 验证结果
6. 当 `./check1` 输出 `TOKEN: ...` 时，任务完成

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `samples/in_1.csv` | 第 1 组原始样板 |
| `samples/out_1.csv` | 第 1 组已验收成品 |
| `samples/in_2.csv` | 第 2 组原始样板 |
| `samples/out_2.csv` | 第 2 组已验收成品 |
| `work/in_1.csv` | 本题待处理文件 |

## 提交规则

- 最终答案文件为 `work/out_1.csv`
- 运行 `./check1` 验证，通过即完成
- CSV 使用 UTF-8 编码，LF 换行

## 提示

- 规则不会在题面中直接给出，样板是唯一依据
- 不要只观察一组样板，应使用全部样板进行交叉验证
- 注意数值精度、日期格式、排序方式等细节
- 可以反复运行 `./check1` 查看是否通过
