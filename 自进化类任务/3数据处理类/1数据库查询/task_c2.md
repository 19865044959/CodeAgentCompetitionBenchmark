# 自进化任务 C-2：2023年违章高发路段统计

## 任务背景

年度报告还需要补充去年的对比数据。请继续使用同一个 `traffic.db` 数据库，拉取 **2023年** 的违章统计。

（数据库文件与上一题相同：`traffic.db`）

## 任务要求

请查询 `traffic.db`，完成以下统计：

```json
{
  "year": "2023",
  "top3_roads": [
    {
      "rank": 1,
      "road_name": "<路段名>",
      "violation_count": <违章次数>,
      "total_fine": <累计罚款金额（元）>
    }
  ],
  "total_violations_2023": <2023年违章总数>,
  "total_fine_2023": <2023年罚款总额>
}
```

## 提交规则

1. 将上述 JSON 写入本任务文件所在目录下的 `answer_c2.json`，完整路径为：`/tmp/自进化类任务/3数据处理类/1数据库查询/answer_c2.json`
2. 写文件时必须使用上述绝对路径（或先 `cd` 到该目录再写），不要使用不带路径的相对文件名
3. JSON 必须格式正确、字段齐全
