# 自进化任务 C-1：2024年违章高发路段统计

## 任务背景

你是人类控制区交通管理局的数据分析师。机器人大战爆发后，战前与战后的违章和事故数据都保存在交通管理数据库系统（SQLite）中。你需要从中提取统计信息，为年度交通治理报告做准备。

数据库文件为 `traffic.db`，存放在本任务文件所在目录：`/tmp/自进化类任务/3数据处理类/1数据库查询/`。**数据库没有附带说明文档**，你需要自行探索其结构。

## 任务要求

请查询 `traffic.db`，完成以下统计：

```json
{
  "year": "2024",
  "top3_roads": [
    {
      "rank": 1,
      "road_name": "<路段名>",
      "violation_count": <违章次数>,
      "total_fine": <累计罚款金额（元）>
    }
  ],
  "total_violations_2024": <2024年违章总数>,
  "total_fine_2024": <2024年罚款总额>
}
```

## 提交规则

1. 将上述 JSON 写入本任务文件所在目录下的 `answer_c1.json`，完整路径为：`/tmp/自进化类任务/3数据处理类/1数据库查询/answer_c1.json`
2. 写文件时必须使用上述绝对路径（或先 `cd` 到该目录再写），不要使用不带路径的相对文件名
3. JSON 必须格式正确、字段齐全
4. 数据必须来源于数据库实际查询结果

## 提示

- 这是一个 SQLite 数据库，使用 `sqlite3` 命令行工具或 Python 的 `sqlite3` 模块
- 数据库没有提供文档，你需要先探索表结构
- 注意日期字段的格式可能不统一
- 建议将探索和查询过程整理为可复用的脚本
