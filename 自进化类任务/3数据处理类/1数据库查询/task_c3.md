# 自进化任务 C-3：各区域违章与事故综合统计

## 任务背景

交通治理报告的最后一部分，需要按**区域（所属区）** 维度，汇总 2024 年的违章与事故数据。

（数据库文件与前面相同：`traffic.db`）

## 任务要求

请查询 `traffic.db`，完成以下统计：

```json
{
  "year": "2024",
  "district_stats": [
    {
      "district": "<所属区名称>",
      "violation_count": <违章次数>,
      "accident_count": <事故次数>,
      "total_injured": <总受伤人数>
    }
  ]
}
```

## 提交规则

1. 将上述 JSON 写入 `answer_c3.json` 文件
2. JSON 必须格式正确、字段齐全

## 提示

- 数据库结构你已经熟悉了，注意表之间的关联关系
- 如果之前总结了可复用的脚本/SQL模板，现在直接套用即可
