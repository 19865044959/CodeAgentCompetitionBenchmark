# 自进化任务 B-2：处理营地物资清单

## 任务背景

继续处理营地的物资清单（`data.csv`），完成统计任务。

## 任务要求

1. 读取本任务文件所在目录下的 `data.csv`（`/tmp/自进化类任务/3数据处理类/2营地物资统计/data.csv`）
2. 筛选出所有 `类别` 为 `"食物"` 的条目
3. 按 `数量` **降序**排列
4. 计算：
   - `count`: 筛选后的条目数
   - `total`: 筛选后所有条目的数量总和
   - `top_item`: 筛选结果中数量最多的物品名称
5. 将结果写入本任务文件所在目录下的 `answer_b2.json`，完整路径：`/tmp/自进化类任务/3数据处理类/2营地物资统计/answer_b2.json`（必须使用绝对路径或先 `cd` 到该目录，勿用不带路径的相对文件名）
